# Передача суммы из команд iPhone

Mini App принимает сумму из URL и открывает «Новый расход» с заполненным полем.
Выберите категорию и нажмите «Сохранить расход». Открытие ссылки само по себе
не записывает транзакцию. Авторизация через Telegram остаётся обязательной.

## Ссылка для iPhone

Для основной Mini App бота:

```text
https://t.me/<bot_username>?startapp=expense_12_50
```

Для Mini App с отдельным коротким именем:

```text
https://t.me/<bot_username>/<app_short_name>?startapp=expense_12_50
```

Замените `<bot_username>` на имя вашего бота без `@`, а `<app_short_name>` —
на короткое имя приложения из BotFather. Для первого варианта основная Mini App
должна быть настроена в BotFather.

`expense_12_50` означает 12,50; `expense_12` — 12. Telegram передаёт payload
в `start_param` / `tgWebAppStartParam`:
[документация Telegram](https://core.telegram.org/bots/webapps#direct-link-mini-apps).
Используйте `_` вместо десятичного разделителя в payload.

В приложении «Команды» соберите такую последовательность:

1. Получите сумму транзакции из вашей автоматизации или действием
   «Запросить ввод» с типом «Число».
2. Отформатируйте число без разделителей тысяч, максимум с двумя знаками
   после запятой.
3. Замените `,` и `.` на `_` действием «Заменить текст».
4. Создайте URL `https://t.me/<bot_username>?startapp=expense_` и подставьте
   результат в конец.
5. Добавьте действие «Открыть URL».

Ссылка откроет Mini App в Telegram. Останется проверить сумму, выбрать
категорию и сохранить расход. Дата — сегодня в Минске; валюта и поездка
определяются текущим режимом приложения и доступны для изменения в форме.

## Прямой URL приложения

```text
https://<mini-app-host>/?amount=12.50
https://<mini-app-host>/?amount=12%2C50
```

Поддерживаются точка и запятая, положительные суммы до 9 999 999 999,99,
не более двух десятичных знаков. Некорректная сумма открывает пустую форму
с сообщением об ошибке. Отмена сохраняет черновик в текущем сеансе;
после успешного сохранения сумма очищается.

Открытие прямого URL в Safari не создаёт Telegram-сессию. Для команды iPhone
используйте ссылку `t.me` выше. При нескольких источниках суммы payload
`expense_…` имеет приоритет над `amount`; `start_param` SDK — над параметрами URL.
