# Замена ранее раскрытых секретов

Удаление файла из рабочей копии или добавление его в `.gitignore` не отзывает
значения, которые уже находились в истории Git. После подготовки этапа 0 владелец
бота должен выполнить замену вне репозитория.

1. Через BotFather отозвать старый токен и выпустить новый `BOT_TOKEN`.
2. В Google Cloud отключить или удалить прежний ключ сервисного аккаунта,
   создать новый ключ и проверить минимально необходимые права на таблицу.
3. Сохранить новые значения только в локальных `.env` и
   `google-credentials.json`; не отправлять их в чат и не добавлять в Git.
4. Обновить секреты среды размещения и перезапустить приложение.
5. Проверить доступ бота и таблицы, затем убедиться, что старые значения больше
   не работают.
6. Отдельно принять решение об очистке истории Git. Перезапись опубликованной
   истории затрагивает всех пользователей репозитория и не заменяет отзыв
   секретов.
