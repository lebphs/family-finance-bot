# Family Finance

Telegram-бот и Mini App для учёта семейных расходов в SQLite с ежедневной выгрузкой в Google Sheets.

## Структура

- `bot/` — Telegram-команды, обработчики расходов, клавиатуры, планировщик
  напоминаний и адаптер таблицы для бота.
- `mini_app/backend/` — HTTP API, авторизация Telegram, сервисы, репозитории
  SQLite, импорт Google Sheets, ежедневная выгрузка и резервное копирование. Бот использует эти же
  репозитории и правила доступа.
- `mini_app/frontend/` — интерфейс React, TypeScript и Vite.
- `config.py` — общая конфигурация из переменных окружения.
- `tests/` — Python-тесты с подменой внешних сервисов.
- `docs/` — требования, план реализации, инструкции запуска и деплоя.
- `deploy/` — конфигурация HTTPS-прокси для VPS.

Бот и Mini App разделены по пакетам, но запускаются одним процессом:
Uvicorn обслуживает API и собранный интерфейс, polling бота работает фоном.
База хранится в постоянном томе; записи и проверки версий выполняются атомарно. Не запускайте второй
экземпляр с тем же токеном.

Расходы, категории, пользователи и настройки напоминаний хранятся в
`STATE_DIR/finance.sqlite3`. API и бот читают базу без обращения к Google.
Права пользователя проверяются по актуальной записи базы на каждом запросе.
Раз в календарный день по времени Минска база выгружается в отдельные листы
`DB Transactions`, `DB Categories`, `DB Trips`, `DB Travel Categories`, `DB Sync`. Правки в Google Sheets
не импортируются обратно. Настройки доступа и напоминаний остаются только в базе.
Резервные копии SQLite хранятся 30 дней в `STATE_DIR/backups`.

Перед первым запуском необходимо импортировать существующую таблицу:
[переход на SQLite](docs/database-migration.md). Пустая база не выгружается.

## Поездки и валюты

В разделе «Поездки» можно создать путешествие, задать даты и валюту,
включить его режим или открыть полный отчёт. Режим персональный:
его включение не меняет ввод расходов у остальных участников семьи.
Категории путешествий хранятся отдельно от повседневных категорий.

В режиме поездки достаточно вводить сумму: поездка, категории и валюта
подставляются автоматически. Для отдельного расхода можно выбрать обычный
учёт или другую валюту. После сохранения форма возвращается к активному режиму.
Для билетов и отелей заранее используйте «Добавить расход в эту поездку»
в её карточке: включать режим поездки для этого не требуется.
Завершённые поездки остаются доступны для отчёта и добавления забытых расходов.
Изменять и завершать поездку может её создатель или администратор.

Исходная сумма сохраняется вместе с эквивалентом в BYN. Пересчёт использует
официальный курс НБРБ на указанную дату оплаты с учётом номинала валюты,
округление до копеек — HALF_UP. Курс кэшируется в SQLite и закрепляется за
расходом; редактирование описания не пересчитывает прошлые суммы. Изменение
даты, валюты или исходной суммы запускает пересчёт. Получить курс на будущую
дату нельзя. Для валюты без курса на выбранную дату предлагается выбрать
другую валюту; при сетевой ошибке форма сохраняет данные для повторной отправки.
API НБРБ: `https://api.nbrb.by/exrates/rates`, параметры `ondate` и `periodicity`.
Поддерживаются ежедневные и ежемесячные таблицы; произвольный сегодняшний
курс вместо исторического не подставляется. Банковские комиссии не учитываются.

Главная сводка и вкладка «Статистика» показывают только обычные расходы.
Поездки исключены из итогов, категорий, динамики, сравнения месяцев и участников,
включая предварительные покупки билетов и отелей. Отчёты путешествий находятся
в отдельной вкладке «Поездки». История транзакций по-прежнему позволяет видеть
все операции и фильтровать их по поездке.
Отчёт путешествия включает все связанные оплаты независимо от дат поездки,
с категориями, участниками, исходными валютами и итогом в BYN.

В Telegram: `/trips` — выбор поездки, отчёт и переключение режима;
`/expense` — начало ввода. Валюту отдельной покупки можно указать вместе
с суммой, например `25 EUR`. После ошибки сохранения `/retry` повторяет
тот же расход без дублирования. Создание и редактирование поездок доступны в Mini App.

Обновление SQLite добавляет таблицы без переписывания старых расходов:
они остаются обычными операциями в BYN. Резервная копия базы включает поездки,
режимы участников и курсы. Выгрузка добавляет валютные поля к `DB Transactions`
и отдельные листы поездок и категорий; исходные `Main`, `Preferences`,
`Transactions` не изменяются. Локальный preview использует только демонстрационные
курсы и не обращается к НБРБ.

## Локальный запуск

Требуются Python 3.11 и Node.js 22.12+ либо Docker Compose.
Создайте `.env` по `.env.example` и разместите `google-credentials.json`
в корне проекта. Значения секретов не добавляйте в Git.

```sh
python -m pip install -r requirements.txt
python -m mini_app
```

Для разработки интерфейса в другом терминале:

```sh
cd mini_app/frontend
npm ci
npm run dev
```

Vite проксирует `/api` на `127.0.0.1:8000`. Для выдачи интерфейса самим API
сначала выполните `npm run build` в `mini_app/frontend`, затем запустите API.
`FRONTEND_DIR` по умолчанию — `mini_app/frontend/dist`; обновите этот путь,
если в существующем `.env` явно указан прежний `frontend/dist`.

Сборка и запуск в Docker:

```sh
docker compose up --build -d
```

Приложение доступно на `http://127.0.0.1:8000`, проверка — `/health`.
Настройки Telegram и локального тестирования описаны в
[инструкции разработки](docs/mini-app-local-development.md).
Деплой: [инструкция VPS](docs/vps-deployment.md).
Передача суммы через URL из команд iPhone: [инструкция и форматы ссылок](docs/iphone-shortcuts.md).

## Проверки

```sh
python -m unittest discover -s tests -v
cd mini_app/frontend
npm test
npm run build
npm run test:e2e
```

Python-тесты не обращаются к рабочему боту и таблице. Миграция запускается
отдельно: `python -m mini_app.backend.migration`; порядок безопасного
применения описан в [инструкции миграции](docs/google-sheets-migration.md).
